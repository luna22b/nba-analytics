##  Statline - NBA Quick Statistics App

🏀 Statline is a web application that allows to quickly look at the most important statistics quickly


## Technologies Used
- React
- TypeScript
- Prisma
- TailwindCSS
- PostgreSQL
- Node.js
- Express


## Why I Built Statline
I wanted an application to quickly view statistics without having to search multiple things up. 
I gathered statistics that I care about the most from an API and organized them, creating a simple
interface for browsing teams and player data. 

## Future Improvements (will be continuously improved as the season starts!)
- Charts
- Real-time games

## Getting Started

1. Clone the repository.

```
git clone https://github.com/your-username/statline.git
```

2. Install the dependencies.

```
npm install
```

or

```
yarn
```

3. Start the development server.

```
npm run dev
```

4. Open your browser and navigate to (or the address in your console):

```
http://localhost:3000
```
